# etu-bot

Небольшой гайд по локальному запуску [etu-bot](https://github.com/abelith/etu-bot).

## Что нужно

- **Docker** и **Docker Compose** — весь запуск идёт через контейнеры.
- **Git** — чтобы склонировать репозиторий.
- **Токен бота** — получить его нужно заранее (например, у @BotFather, если это Telegram-бот).

> Про железо: для малой нагрузки хватит любого VPS. В нормальных условиях инфраструктуру (Redis, БД и т.д.) поднимают на отдельном железе, но для нас это оверкилл — так что просто локальный запуск через Docker.

## Шаги

### 1. Склонировать репозиторий

```bash
git clone https://github.com/abelith/etu-bot
cd etu-bot
```

### 2. Создать `.env` в корне проекта

В корне репозитория создай файл `.env` и положи туда токен:

```env
TOKEN=твой_токен_здесь
```

### 3. Запустить

```bash
docker compose up
```

Всё. Бот поднимется вместе со своими сервисами.

## Если что-то пошло не так

- **`docker compose up` ругается на отсутствующий `.env`** — проверь, что файл лежит именно в корне проекта и называется ровно `.env` (без `.txt` и прочего).
- **Контейнеры падают сразу после старта** — скорее всего проблема с `TOKEN`. Убедись, что он валидный и без лишних пробелов/кавычек.
- **Порты заняты** — глянь `docker-compose.yml`, там могут быть прописаны пробросы портов; при конфликте поменяй их на свободные.
